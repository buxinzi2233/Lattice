# Lattice 使用指南

工具序列由分组标题和工具行组成。点击标题折叠或展开；拖动标题改变分组顺序；拖动工具可在组内排序或投放到其他组，投放到折叠组时追加到末尾。搜索或状态筛选生效时重排暂时禁用，匹配分组会临时展开且不会改写折叠设置。

“定位完整日志”会在文件管理器中选中持久化日志；“清空视图”只清除窗口缓冲，不删除文件。字号面板支持 80% 到 150%。

启动动画默认每日首次显示。设置侧栏可改为每次显示或关闭，也可预览、清理本地图片缓存并查看版权与安全声明。远程素材失败不会阻塞主界面。

常见故障：损坏的 `layout.json` 会自动备份为 `layout.json.corrupt-*` 并按确定性顺序重建；工具无法停止时检查其是否主动脱离原进程树；Windows 便携包首次启动被拦截时检查 Defender 记录和 ZIP 是否完整。

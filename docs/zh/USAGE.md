# Lattice 使用指南

工具序列由分组标题和工具行组成。点击标题折叠或展开；拖动标题改变分组顺序；拖动工具可在组内排序或投放到其他组，投放到折叠组时追加到末尾。搜索或状态筛选生效时重排暂时禁用，匹配分组会临时展开且不会改写折叠设置。状态筛选按钮“运行 / 静止 / 异常”分别对应正在运行、已正常停止、已退出的工具；“静止”不再包含已退出（异常）的工具，崩溃的工具需在“全部”或“异常”下查看。

“定位完整日志”会在文件管理器中选中持久化日志；“清空视图”只清除窗口缓冲，不删除文件。两套工作台共用设置面板：“界面主题”下方的“界面缩放”支持 80% 到 150%，可用滑块或加减按钮调整，并一键恢复 100%。

添加工具时选择程序或启动脚本即可。Lattice 会检测入口、解释器、工作目录和启动参数，并在保存及每次启动前执行同一套预检。Python 项目没有可用环境时，界面会列出准备命令、目标 `.venv` 和是否联网；只有点击确认后才会执行，界面会持续显示当前命令和状态目录中的 `setup` 完整日志。环境准备失败或取消不会写入工具配置，也不会覆盖或删除已有环境；Lattice 会保留不完整标记，下一次确认时继续准备，全部成功后才将环境视为可用。命令、Shell、环境变量、健康地址和超时位于高级设置；旧配置会以原始命令模式打开。

新进程先显示“正在启动”。普通进程稳定存活后进入“运行中”；检测到本地 URL、显式 HTTP 地址或 TCP 端口时，健康探测成功后才进入“运行中”。超时状态不会终止慢速服务，Lattice 会保留进程并继续低频探测。启动期间秒退会显示退出码、最近输出和完整日志路径，不再短暂显示成功。

内置主题包括 `lattice-day`、`lattice-night` 和使用独立档案工作台布局的 `lattice-archive`。自定义主题放在 `~/.config/tooldeck/themes.d/`（Windows 为 `%APPDATA%\tooldeck\themes.d\`），可用 `extends` 继承任一内置主题；继承 `lattice-archive` 会同时继承其 `archive` 界面壳。在设置面板打开主题目录，写入 JSON 后点击重载。损坏的单个主题会被报告并隔离，不会阻止内置主题启动。

默认图形界面是可替换前端。运行 `tooldeck frontends` 查看已安装适配器，运行 `tooldeck --frontend ID` 启动指定前端；不带子命令时也可用 `TOOLDECK_FRONTEND` 设置默认值。

启动动画默认每日首次显示。设置侧栏可改为每次显示或关闭，也可预览、清理本地图片缓存并查看版权与安全声明。远程素材失败不会阻塞主界面。

常见故障：损坏的 `layout.json` 会自动备份为 `layout.json.corrupt-*` 并按确定性顺序重建；工具无法停止时检查其是否主动脱离原进程树；Windows 便携包首次启动被拦截时检查 Defender 记录和 ZIP 是否完整。

若现有运行状态 JSON 损坏，Lattice 会拒绝再次启动对应工具以避免重复进程。确认原进程已经退出后，备份并移走错误信息中指出的状态文件，再重试启动。

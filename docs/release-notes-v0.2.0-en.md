# Lattice 0.2.0

Lattice 0.2.0 adds persistent group/tool drag ordering, collapsible groups, a stable vector icon system, adjustable interface scaling, and an optional Rhine Lab-inspired startup experience with offline fallback. Windows and Linux source installers can repair Lattice dependencies without touching tool environments.

Artifacts include the wheel, source archive, Windows portable ZIP, and SHA256 checksums. Third-party artwork and quotes are not distributed with the source or release.
